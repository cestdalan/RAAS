# Art Gallery — Lumen Artspace

A single-page, scroll-animated luxury editorial website for fine art gallery **Lumen Artspace**, featuring scroll-scrubbed choreography, dark aesthetics, and an interactive 3D virtual exhibition room.

## Features

- **Preloader**: Minimalist counter animating from `0% → 100%`.
- **Hero Reveal**: Block wipe revealing headline *"Heritage In Art"* and framed masterworks.
- **Pinned Hero Transition**: Smooth sticky hero transition into *"A Journey Through Time"*.
- **Scatter-to-Grid Mosaic**: Artworks drift from scattered rotation and snap cleanly into an editorial mosaic grid.
- **3D Virtual Gallery Room**: Interactive 3D museum room with camera orbit controls and scroll-linked dolly push-in.
- **Watermark & Curatorial Philosophy**: Oversized typography and curatorial hallway backdrop.
- **Cross-Axis Parallax Rail**: Staggered horizontal artwork gallery rail (*"Reflection — Of Art"*).
- **Inquiry CTA & Footer**: Floating gold orb inquiry button and full luxury editorial footer.

## Tech Stack

- **React 18**
- **Vite**
- **Tailwind CSS**
- **GSAP + ScrollTrigger**
- **Lenis Smooth Scroll**
- **Lucide Icons**
